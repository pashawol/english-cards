# Plan — Sonnet (код): примеры на обороте + свайп-жесты

2. В режиме изучения добавить свайп-жесты: влево = «знал», вправо = «не знал». Кнопки остаются как fallback.

## Дизайн данных (уже зафиксирован)

В `data/*.json` каждая карточка получит опциональное поле `examples`:

```json
{
  "ru": "обвинять в",
  "en": "accuse of",
  "examples": [
    { "en": "They <b>accused</b> him <b>of</b> stealing the money.",
      "ru": "Они обвинили его в краже денег." },
    { "en": "She has been <b>accused</b> <b>of</b> lying.",
      "ru": "Её обвинили во лжи." }
  ]
}
```

- `examples` — массив объектов `{en, ru}`, опциональное поле, может отсутствовать или быть пустым
- В `en` — HTML-строка с `<b>...</b>` тегами вокруг конструкции
- Безопасно рендерить через `innerHTML`, т.к. данные свои (не пользовательский ввод)

## Что нужно сделать

### A. Рендер примеров на обороте карточки

**Разметка** (в `index.html`, внутри обороту `.flip-card-back`):

```html
<div class="card-examples" id="card-examples" hidden>
  <button class="examples-toggle" id="examples-toggle" type="button">
    <span class="examples-toggle-label">примеры</span>
    <span class="examples-toggle-chev">▾</span>
  </button>
  <div class="examples-body" id="examples-body" hidden>
    <!-- заполняется JS -->
  </div>
</div>
```

**Поведение в `app.js`:**

- При смене карточки:
  - если у текущей карточки нет `examples` или он пустой — `card-examples` скрыт (`hidden`)
  - иначе — показать `card-examples`, скрыть `examples-body` (свернутое состояние по умолчанию), повернуть шеврон
  - заполнить `examples-body`: для каждого примера создать DOM-узлы:
    ```html
    <div class="example">
      <div class="example-en"><!-- innerHTML из ex.en --></div>
      <div class="example-ru"><!-- textContent из ex.ru --></div>
    </div>
    ```
  - **EN — через `innerHTML`** (там есть `<b>`)
  - **RU — через `textContent`** (на всякий случай, даже если данные свои)
- Тап по `examples-toggle` — переключает `hidden` у `examples-body`, поворачивает шеврон.
- Тап по `examples-toggle` ИЛИ `examples-body` — НЕ должен флипать карточку и НЕ должен записывать ответ. Использовать `event.stopPropagation()` или проверять `event.target.closest('.card-examples')` в обработчиках флипа/свайпа и игнорировать.

### B. Свайп-жесты

**Где:** на `.flip-card` в study-режиме.

**Логика:**

- `touchstart`: запомнить `startX`, `startY`, `startT`
- `touchmove`: вычислить `dx = currentX - startX`, `dy = currentY - startY`
  - если `Math.abs(dx) < 10 && Math.abs(dy) < 10` — ничего не делать (это пока ещё может быть тап)
  - если `Math.abs(dy) > Math.abs(dx)` — отменить свайп (это, вероятно, скролл; вернуть карточку в исходное положение)
  - иначе — `transform: translateX(dx) rotate(dx*0.05deg)` на карточке + цветовой overlay (зелёный при `dx < 0`, красный при `dx > 0`), интенсивность пропорциональна `Math.min(1, Math.abs(dx) / threshold)`
- `touchend`:
  - если `Math.abs(dx) >= 80` (порог) — анимировать улёт за экран в ту же сторону, после анимации записать ответ:
    - `dx < 0` (влево) → ответ «знал», та же логика что и кнопка «знал»
    - `dx > 0` (вправо) → ответ «не знал», та же логика что и кнопка «не знал»
  - иначе — анимировать возврат `transform: translateX(0) rotate(0)`, сбросить overlay

**Важно:**

- Свайп активен независимо от того, флипнута ли карточка (как и кнопки сейчас, согласно CLAUDE.md «знал / не знал immediately records answer»).
- Свайп **не должен** срабатывать, если касание началось внутри `.card-examples` (там пользователь раскрывает примеры, и палец может скользить).
- Кнопки `знал` / `не знал` должны продолжать работать как раньше.
- Не ломать существующую логику тапа по карточке для флипа: тап = `Math.abs(dx) < 10 && Math.abs(dy) < 10` И короткое время (`< 250ms`).
- Не трогать `recomputeSessionState`, `session.answers`, кнопку «← назад» — fragile зона.

### C. Стили (`styles.css`)

- `.card-examples` — отдельный блок под основным словом на обороте, отступ сверху, выравнивание по левому краю
- `.examples-toggle` — компактная кнопка, использует `var(--accent)` или существующий стиль кнопок
- `.examples-toggle-chev` — `transition: transform .2s`, при раскрытии — `transform: rotate(180deg)` (через класс `.open`)
- `.examples-body` — список с отступами между примерами
- `.example-en b` — выделение жирным с акцентным цветом: `color: var(--accent); font-weight: 700;`
- `.example-ru` — приглушённый цвет (`var(--text-muted)` или аналог)
- Свайп: класс `.swiping` на `.flip-card` отключает CSS-transition на `transform`, чтобы движение шло сразу за пальцем; при отпускании класс снимается и transition возвращается → плавный возврат / улёт.
- Цветовой фидбек свайпа: можно через дополнительный псевдоэлемент или overlay-div, появляющийся слева/справа.
- **Тёмная тема** — проверить контрасты и читаемость и `<b>`, и приглушённого RU.

## Тестирование (вручную)

1. `node --check app.js` — должен проходить.
2. Запустить `npx serve .`, открыть в браузере, включить mobile emulation (DevTools → Toggle device toolbar → iPhone).
3. **Для проверки рендера примеров** временно добавить `examples` в первые 1-2 карточки одного файла (например `data/07-verb-prep-1.json`) — это **временный** тест, перед коммитом удалить.
4. Чек-лист:
   - [ ] запустить набор → флип → виден блок «примеры», карта без флипа тоже работает
   - [ ] тап по «примеры» — раскрывается, EN с жирным цветным выделением, RU приглушённым
   - [ ] тап по примерам/кнопке не флипает карточку и не засчитывает ответ
   - [ ] свайп влево → улёт + засчитывается «знал», следующая карточка
   - [ ] свайп вправо → улёт + засчитывается «не знал»
   - [ ] короткий тап = флип (свайп не срабатывает)
   - [ ] вертикальный скролл (если он есть на study-экране) не триггерит свайп
   - [ ] кнопки `знал` / `не знал` работают
   - [ ] кнопка «← назад» работает, ответы пересчитываются корректно
   - [ ] карточка без `examples` — никакого блока на обороте
   - [ ] **тёмная тема**: цвета жирного, RU, кнопки, overlay свайпа — все читаемы
   - [ ] на узком iPhone-экране (375px) ничего не вылезает
